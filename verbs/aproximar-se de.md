# aproximar(-se de) — приближаться

**Слово:** aproximar(-se de) — приближаться (к чему-либо), подходить ближе; (перен.) сближаться, быть близким по значению
**Произношение:** апрусимА́р, /ɐ.pɾɔ.siˈmaɾ/

---

## 3 примера (европейский португальский)

1. **O comboio aproxima-se da estação.** — Поезд приближается к станции.
2. **Aproxima-te! Não te ouço bem.** — Подойди ближе! Я тебя плохо слышу.
3. **O resultado aproxima-se do valor real.** — Результат приближается к истинному значению.

---

## Этимология

Из позднелатинского **approximāre** — «приближаться, подходить вплотную». Составлено из двух элементов:

- **ad-** — латинский префикс «к, по направлению к» (перед *p* ассимилируется в *ap-*)
- **proximus** — латинское прилагательное «ближайший, следующий» — **супerlатив** от *prope* («рядом, вблизи»)

*Prope* восходит к ПИЕ **\*prokʷe** — от **\*pro-** («вперёд, впереди») + энклитика **\*-kʷe** («и»). Буквально: «выдвинутый вперёд». Из того же ПИЕ-корня **\*per-** / **\*pro-** — «перед, вперёд, к» — растут целые леса слов в десятках языков.

Параллель: *proximus* относится к *prope* так же, как английское «**next**» к «**nigh**» (оба — супerlативы слова «близкий» в своих языках).

Цепочка: **ПИЕ \*per- / \*pro-** → лат. **prope** → лат. **proximus** → позднелат. **approximāre** → порт. **aproximar**

## Родственники

### По корню *proximus / prope* — в европейских языках

| Язык | Слово | Значение |
|------|-------|---------|
| **Испанский** | *aproximar* / *próximo* / *prójimo* | приближать / ближайший / ближний (человек, сосед) |
| **Итальянский** | *approssimare* / *prossimo* | приближать / ближайший; «il prossimo» = ближний (библ.) |
| **Французский** | *approcher* / *approche* / *prochain* | приближаться / подход / следующий, ближайший |
| **Английский** | *approximate* / *proximity* / *approach* / *reproach* | приблизительный / близость / подходить / упрекать |
| **Немецкий** | *approximieren* / *Proximität* | приближать (научн.) / близость (заимств. из латыни) |
| **Русский** | **проксимальный** (анат.) / **приблизительно** (кальк.) | ближний к центру тела / примерно |

> **Английская связь — неожиданная!** Четыре совершенно разных английских слова — одна семья:
> - **approximate** («приблизительный») — прямо из *approximāre*
> - **proximity** («близость») — из лат. *proximitas*
> - **approach** («подходить») — через старофр. *approcher* < вульг. лат. *\*appropiāre* (тот же *ad-* + *prope*)
> - **reproach** («упрекать») — через старофр. *reproche* < вульг. лат. *\*repropiāre* (*re-* + *prope*): «снова приблизить [неприятное к лицу]» — буквально «сунуть носом».
>
> Когда вы **reproach** кого-то — вы этимологически *подходите к нему вплотную*. Упрёк как вторжение в личное пространство.

### Внутри португальского — от корня *próximo / aproximar*

- **próximo** — ближайший; следующий (*o próximo autocarro* = следующий автобус)
- **proximidade** — близость, соседство
- **aproximação** — приближение, сближение; (матем.) аппроксимация
- **aproximado** — приблизительный, примерный
- **aproximadamente** — приблизительно, около
- **propinquidade** — (книжн.) близость, родство (< лат. *propinquus*)
- **propínquo** — (книжн./архаич.) близкий, родственный

### Медицинские и научные термины

- **proximal** (анат.) — проксимальный: «*extremidade proximal do fémur*» = проксимальный конец бедренной кости (ближний к туловищу)
- **distal** — дистальный (антоним: дальний от центра тела)
- **aproximação** (матем./фís.) — аппроксимация, приближение к истинному значению
- **Proxima Centauri** — ближайшая к Солнцу звезда; само название — латинский супerlатив *proximus* в действии

### По ПИЕ \*per- / \*pro- («вперёд, впереди») — дальние родственники

- Лат. **prior** («прежний») → порт. **prior** / **prioridade**
- Лат. **primus** («первый») → порт. **primeiro**, исп. **primero**, итал. **primo**, фр. **premier**, англ. **prime**
- Греч. **pérā** («по ту сторону, дальше») → **пери-** в научных терминах (*periférico*, *perímetro*)
- Санскр. **pára** («дальний, иной») — тот же корень
- Англ. **first**, **fore**, **for-**, **far** — через протогерм. \*fura (родство с *pro-*)
- Рус. **пред-**, **перед**, **про-**, **при-** — через праслав. **\*per-** / **\*pro-**

Так что **aproximar** и русское **приближаться** — не просто семантические близнецы, но и этимологические родственники через ПИЕ!

## Три карты таро

**Луна (The Moon, XVIII)** — две башни на горизонте, дорога, уходящая вдаль: путник *приближается*, но никогда не достигает. *Aproximar-se* как вечное движение к цели, которая отступает. Аппроксимация — но не совпадение.

**Колесница (The Chariot, VII)** — победное движение вперёд, *ad* цели; воля как вектор приближения. Префикс *ad-* в *approximāre* — это и есть колесница: направленная сила, не останавливающаяся.

**Влюблённые (The Lovers, VI)** — двое, стоящие лицом к лицу: предельное *aproximar-se de*, сближение двух орбит. *Proximidade* как основа союза. И ангел над ними — свидетель того, что полное слияние невозможно, только приближение.
