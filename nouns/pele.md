**pele** — кожа, шкура, мех

**Произношение:** ПЕ-ле /ˈpɛlɨ/

**Примеры:**
- Pele macia. — Нежная кожа.
- Salvar a pele. — Спасти свою шкуру.
- Pele de galinha. — Гусиная кожа.

**Этимология:**
От старогалисийско-португальского *pele*, из латинского *pellem* (винительный падеж от *pellis* — «кожа, шкура, пергамент»), из праиталийского *\*pelnis*, из праиндоевропейского *\*pel-* («покрывать, заворачивать; кожа, шкура, ткань»). Путь: ПИЕ *\*pel-* → праиталийское *\*pelnis* → латинское *pellis* → старогалисийско-португальское *pele* → португальское *pele*.

**Родственные слова:**
- Испанский: *piel* (кожа)
- Итальянский: *pelle* (кожа)
- Французский: *peau* (кожа — из вульгарнолатинского *\*pella*, из *pellem*, винительного падежа)
- Румынский: *piele* (кожа)
- Английский: *peel* (снимать кожуру — вероятно, под влиянием *pellis*); *pelt* (шкура зверя — из ПИЕ *\*pel-*); *pellicle* (плёнка, оболочка — из *pellicula*, уменьшительного от *pellis*); *pellagra* (пеллагра, кожная болезнь — из итальянского *pelle* + *agra*, «шершавая кожа»); *film* (плёнка — из древнеанглийского *filmen*, «оболочка, тонкая кожица», из протогерманского *\*fello(m)*, из того же ПИЕ *\*pel-* — не через латынь, а через германскую ветвь!)
- Немецкий: *Fell* (шкура животного — из протогерманского *\*fellą*, из ПИЕ *\*pel-* — прямой когнат!)
- Русский: *плёнка* (тонкая плёнка, оболочка — из праславянского *\*plěva*, из ПИЕ *\*pel-*!); *пелена* (пелёнка, покров — из праславянского *\*pelenà*, из того же ПИЕ *\*pel-*!)
- В португальском: *pelagem* (масть, мех животного); *pelar* (снимать кожу, ощипывать); *película* (плёнка, оболочка — из латинского *pellicula*); *pêlo* (волосяной покров тела — родственно); *peleteria* (меховой магазин)
- Медицина: *pellicle* (тонкая оболочка), *pellagra* (пеллагра — заболевание кожи при дефиците ниацина)

**Три карты таро:**

1. **Одно слово, семь языков** — Карта изображает круглый стол, за которым сидят семь фигур: португалец (*pele*), испанец (*piel*), итальянец (*pelle*), француз (*peau*), румын (*piele*), немец (*Fell*) и русский (*плёнка*). В центре стола — листок с надписью ПИЕ *\*pel-*. Каждый держит кусок кожи — одного и того же древнего слова, которое расщепилось на семь форм за четыре тысячи лет. Французское *peau* больше всего изменилось, но история помнит: *pellem → peau*. Карта о том, как праязыковой корень живёт одновременно в десятках языков.

2. **Кожа — плёнка — кино** — Триптих: слева — первобытный человек выделывает *pellis*, шкуру убитого зверя; в центре — викторианский химик наносит светочувствительное покрытие на стеклянную пластину (*film* в значении «тонкий слой», 1845 год); справа — зрители немого кино смотрят на экран (1895 год). Под каждой сценой — этимологическая стрелка: *\*pel-* → *\*fello(m)* → *filmen* → *film*. Карта о том, как слово «кожа» стало словом «кино» — через германскую ветвь, минуя латынь, сохранив смысл «тонкого покрытия».

3. **Шкура как валюта** — Средневековый рынок: торговец мехом раскладывает *peles* — шкуры соболя, лисы, бобра. Рядом — монах переписывает манускрипт на *pergamena* (пергамент — тоже из *pellis*, обработанная кожа). Внизу — нотариус заворачивает документ в *pell*, кожаный свиток. Карта о том, что *pellis* была буквально основой средневековой экономики: из неё шили одежду, делали книги, хранили документы — и все эти смыслы живут в одном португальском слове *pele*.
