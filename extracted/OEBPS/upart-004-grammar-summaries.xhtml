Contractions

  • de + as = das
  • de + este = deste

  • em + umas = numas
  • em + este = neste
  • em + esta = nesta

(The same happens with the other demonstratives isto, isso, aquilo, esta, etc.)

  • a + aquela = àquela

  • a + aquelas = àquelas

Gender and number

How to transform an adjective

  • Masculine adjectives ending in -o change to -a (bonito > bonita)
  • Adjectives ending in -e have the same ending in both genders (casa grande / carro grande)

How to form the plural of nouns

  • Singular ending in -a adds -s (cama > camas)
  • Singular ending in -o adds -s (carro > carros)
  • Singular ending in -r adds -es (professor > professores)
  • Singular ending in -m transforms into -ns (álbum > álbuns)

Note: there are other cases not covered in this book.

How to form the plural of adjectives

  • Singular ending in -a / -o / -e adds -s (bonita > bonitas / alto > altos / grande > grandes)

Reflexive pronouns

verb lembrar-se (to remember) - example

  • eu lembro-me
  • tu lembras-te
  • ele lembra-se
  • nós lembramo-nos (remove the final -s from the conjugation)
  • vocês lembram-se
  • eles lembram-se

Indirect complement pronouns

verb dar (to give) - example

  • tu dás-me (you give me)
  • eu dou-te (I give you)
  • eu dou-lhe (I give him/her/you, singular - formal)
  • ele dá-nos (he gives us)
  • eu dou-vos (I give you)
  • ela dá-lhes (she gives them/you, plural - formal)

Here are a few words that force the personal pronoun to be placed before the verb:

  • nunca (never)
  • também (also)
  • se (if)
  • não (negative sentence)

Verbs structures

The main verb is conjugated in the present tense, unless when stated otherwise in the list below.

  • acabar (simple past) + de + infinitive: to have just done something
  • adorar + infinitive: to love doing something
  • ajudar + a + infinitive: to help doing something
  • andar + a + infinitive: to have been doing something
  • andar + adjective: to b a certain way lately
  • começar + a + infinitive: to start doing something
  • conseguir + infinitive: to be able to do something mentally/physically
  • continuar + a + infinitive: to continue to do something
  • deixar + de + infinitive: to stop doing something
  • desistir + de + infinitive: to quit doing something
  • dever + infinitive: must do something
  • dever (imperfect) + infinitive: should do something
  • estar + a + infinitive: to be doing something now
  • gostar + de + infinitive: to like to do something (or + noun)
  • ir + infinitive: to do something in the future
  • poder + infinitive: can do something
  • precisar + de + infinitive: to need to do something (or + noun)
  • querer + infinitive: to want to do something (or + noun)
  • saber + infinitive: to know how to do something
  • tentar + infinitive: to try to do something
  • ter + de + infinitive: to have to do something
